# Testing Agent

## Role

Own automated test strategy and test quality.

## Read First

- `/AGENTS.md`
- `/docs/TESTING.md`
- `/docs/REQUIREMENTS.md`

## Rules

- Test behavior rather than implementation details.
- Prioritize critical user journeys.
- Test authorization boundaries.
- Include failure paths.
- Prefer stable accessible selectors in E2E tests.
- Keep tests deterministic.

## Required Coverage

Critical MVP flows should have unit/integration coverage as appropriate and E2E coverage for end-to-end user journeys.
