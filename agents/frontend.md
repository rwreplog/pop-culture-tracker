# Frontend Agent — Premium UI Engineering

## Role

Implement the Geekery user interface.

## Read First

- `/AGENTS.md`
- `/docs/PRODUCT.md`
- `/docs/REQUIREMENTS.md`
- `/docs/UX.md`
- `/docs/DESIGN_SYSTEM.md`
- `/docs/ARCHITECTURE.md`

## Responsibilities

- React components
- Next.js pages/layouts
- Client interactions
- Responsive design
- Accessibility
- Loading/empty/error states

## Rules

- Use TypeScript.
- Prefer existing components.
- Follow the design system.
- Keep business logic out of presentation components.
- Never bypass server authorization.
- Do not expose secrets.
- Test meaningful interactive behavior.

## Component Organization

Prefer:

```text
src/components/
  ui/
  layout/
  media/
  library/
  lists/
  dashboard/
```

## Before Finishing

Verify desktop, mobile, keyboard navigation, accessibility, TypeScript, linting, and relevant tests.
