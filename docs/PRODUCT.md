# Geekery — Product Vision

## Vision

Create the best premium personal hub for tracking everything a person watches, reads, plays, listens to, and experiences.

## Target User

A person who consumes multiple forms of media and currently tracks them across separate services, notes, spreadsheets, wishlists, or memory.

## Product Pillars

**Experience bar:** Geekery should feel like a polished, category-defining consumer product—not a CRUD database or hobby project. Every major interaction should feel intentional, fast, refined, and trustworthy.

1. Track — know what you are currently consuming.
2. Organize — create lists and collections.
3. Remember — retain history, ratings, notes, and dates.
4. Discover — find new media.
5. Decide — help determine what to experience next.

## Core User Loop

Discover → Add → Organize → Experience → Track Progress → Rate/Review → Reflect → Discover

## Media Types

Initial:

- Movie
- TV show
- Game
- Book
- Comic

Future:

- Manga
- Anime
- Music
- Album
- Podcast
- Audiobook
- Board game

## Statuses

Common:

- Want to Experience
- Currently Experiencing
- Completed
- Paused
- Abandoned

Media types may expose friendlier labels such as Want to Watch, Watching, Watched, Want to Play, Playing, Completed, etc.

## Lists

Users can create custom lists. Lists may eventually contain mixed media.

Example:
**Rainy Day**

- Stardew Valley
- The Lord of the Rings
- A favorite comic
- A lo-fi album

## Long-Term Features

- Smart backlog
- Personalized recommendations
- "What should I do tonight?"
- Time-aware recommendations
- Mood-aware recommendations
- Statistics
- Goals
- Public profiles
- Friends/following
- Shared and collaborative lists

## Experience Principles

- Premium before feature-heavy.
- Personalization should make the product feel increasingly tailored to the user.
- Discovery should feel editorial and cinematic, not like a spreadsheet.
- Information density should be controlled through hierarchy, progressive disclosure, and excellent defaults.
- Every screen should look production-ready enough to ship to a paying customer.

## Non-Goals

Initially do not:

- Host media
- Replace streaming services
- Become a marketplace
- Become a social network
- Track every possible metadata field
- Gamify every interaction
